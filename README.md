# أكون | جدول الإتاحة — AKUN Availability

موقع يعرض جدول إتاحة الجلسات الفلكية لكل منتجع.

- **يتولد تلقائياً كل شهر:** يحدد ليلة القمر أو الفلك العربي لكل جلسة، ويحسب طور القمر، ويضيف الأحداث الفلكية.
- **تقدر تعدّل عليه:** من لوحة إدارة سهلة بدون أي كود.

| الصفحة | الرابط |
|---|---|
| الموقع (للموظفين) | `https://<حسابك>.github.io/<المستودع>/` |
| لوحة التعديل (بالإيميل والرمز) | زر «تعديل» في الموقع، أو `…/admin.html` |

---

## ١) التركيب (مرة وحدة، ١٠ دقائق تقريباً)

1. أنشئ مستودعاً جديداً من [github.com/new](https://github.com/new)، مثلاً باسم `akun-availability`:
   - اختر **Public**، لأن GitHub Pages المجاني للمستودعات العامة فقط.
   - **لا** تضف README.
2. ارفع **كل محتويات** هذا المجلد: **Add file ← Upload files**، ثم **Commit changes**.
   > ⚠️ مجلد `.github` مخفي في بعض الأجهزة. تأكد إنه انرفع، لأن فيه ملف التشغيل التلقائي. لو ما انرفع: **Add file ← Create new file**، اكتب الاسم `.github/workflows/site.yml` والصق محتوى الملف.
3. ادخل **Settings ← Pages** وتحت **Source** اختر **GitHub Actions**.
4. ادخل **Actions**:
   - إذا طلب منك تفعيلها، فعّلها.
   - افتح **Generate & deploy** واضغط **Run workflow**.

   بعد دقيقتين يظهر رابط الموقع في **Settings ← Pages**.

### الدخول للتعديل

- في الموقع زر **«تعديل»** فوق، أو افتح `admin.html` مباشرة.
- الحساب الأساسي:
  - الإيميل: **wleed@akun.com**
  - الرمز: **123456789**
- **أول دخول فقط:** يطلب الموقع ربطه بـ GitHub مرة وحدة، بمستودع ومفتاح وصول (Token).
  - ادخل **Settings** (إعدادات حسابك) ← **Developer settings** ← **Fine-grained tokens** ← **Generate new token**.
  - في **Repository access** اختر هذا المستودع فقط.
  - في الصلاحيات اختر **Contents: Read and write** و**Actions: Read and write**.
- المفتاح ينحفظ داخل `data/auth.json` **مشفّراً** برمزك السري. بعدها أي مستخدم يدخل بإيميله ورمزه من أي جهاز بدون مفتاح.
- من «الحساب والمستخدمين» تقدر تغيّر الرمز السري، وتضيف موظفين أو تحذفهم.

> ⚠️ **غيّر الرمز 123456789 بعد أول دخول.** ملف `auth.json` منشور مع الموقع، والرمز الضعيف يمكن تخمينه بسرعة، ومن يخمّنه يقدر يعدّل الجدول. الرمز الطويل (12 حرفاً أو أكثر) يحمي المفتاح المشفّر.
> وفي حال أي تعديل غير مرغوب: كل تغيير محفوظ في سجل GitHub ويمكن استرجاعه، وتقدر تلغي المفتاح من GitHub في أي لحظة.

## ٢) كيف يشتغل التوليد التلقائي

- **في ١ و١٥ من كل شهر:** يشتغل GitHub Action ويولّد الشهر الحالي والشهرين اللي بعده لكل منتجع، إذا ما كانت موجودة. بعدها ينشر الموقع.
- **قاعدة الجلسات:** **ليلة القمر** إذا كانت إضاءة القمر ≥ ٣٠٪ وكان فوق الأفق نصف الجلسة على الأقل، أو ثلثها إذا كان يشرق أثناء الجلسة. غير كذا تكون **الفلك العربي**. القاعدة تطابق جدول Six Senses لأكتوبر ٢٠٢٦ (١٨ من ١٨ ليلة)، وجداول Desert Rock.
- **الأحداث المحسوبة تلقائياً:**
  - المحاق، والتربيع الأول، والبدر، والقمر العملاق.
  - اقتراب القمر من الكواكب ومن الثريا وقلب الأسد والسماك وقلب العقرب والدبران وخلية النحل.
  - تقابل الكواكب، وأقصى استطالة للزهرة وعطارد، واقتران كوكبين.
  - الانقلابات والاعتدالات.
  - ذروة زخات الشهب الرئيسية.
  - الخسوفات.

  ما يُسجَّل إلا الحدث اللي يقع وقت الجلسات.
- **تعديل القاعدة لمنتجع معيّن:** تقدر تغيّرها في `data/resorts.json` عن طريق `rules`، مثلاً `"rules": {"lunar_min_illum": 40}`.

> **التعديلات اليدوية ما تنمسح أبداً.** التوليد يكتب في `data/<المنتجع>/<الشهر>.json`، وتعديلاتك تنحفظ في ملف منفصل `…<الشهر>.edits.json`، والموقع يدمجهم وقت العرض.

## ٣) التعديل من لوحة الإدارة

> **وين ينحفظ التعديل؟**
> - على GitHub Pages: في ملفات المستودع، ويظهر لكل الزوار خلال دقيقة إلى دقيقتين.
> - في نسخة claude.ai: في قاعدة بيانات الصفحة، ويظهر فوراً. هذي النسخة تحتاج إن الزائر يكون مسجّل دخول في Claude، واللي يعدّل لازم تكون الصفحة مشاركة معه بصلاحية Contributor أو Editor.

- **اسم الجلسة:** تسمّي جلسة يوم معيّن، مثل «جلسة خاصة – عائلة الأحمد»، والاسم يظهر في الموقع.
- **لون الحدث:** تختاره من الدائرة الملونة جنب تاريخ الحدث، أو من نافذة الفعالية.
- **تغيير جلسة:** اضغط على الجلسة، واختر الفلك العربي أو ليلة القمر أو «بدون جلسة» (ما تظهر في الموقع)، أو اكتب اسم تجربة مخصص مثل `Private Event`.
- **وقت مختلف ليوم واحد:** من نفس قائمة الجلسة، تحت «وقت هذا اليوم فقط».
- **⏰ أوقات الجلسات:** تعدّل أوقات جلسات المنتجع وأسماءها وأيام التشغيل، والجداول القادمة تتولد من جديد تلقائياً. الخانة المعدّلة يظهر عليها إطار ونقطة برتقالية، وتقدر ترجّعها للتلقائي من نفس القائمة.
- **يوم كامل:** اضغط على رقم اليوم، ومنه تقدر تغلق اليوم كاملاً، أو تخلي كل جلساته نوع واحد، أو ترجّعه للتلقائي، أو تضيف فعالية فيه.
- **الفعاليات:**
  - «+ إضافة فعالية»: تكتب العنوان والوصف بالعربي والإنجليزي، وتحدد الأيام والجلسات.
  - الأحداث التلقائية: تقدر تخفيها، أو تعدّل نصها.
- **حفظ ونشر:** يحفظ التعديل في GitHub، ويظهر **لكل مستخدمي الموقع** خلال دقيقة إلى دقيقتين.
- **⚙︎ توليد شهر:** يولّد شهراً معيّناً فوراً بدل ما تنتظر الموعد التلقائي.

## ٤) إضافة منتجع جديد

افتح `data/resorts.json` في GitHub (اضغط ✏️)، وأضف عنصراً داخل `"resorts"`:

```json
{
  "id": "southern-dunes",
  "name": { "en": "Six Senses Southern Dunes", "ar": "سكس سنسز الكثبان الجنوبية" },
  "aliases": ["southern dunes", "six senses", "سكس سنسز", "الكثبان"],
  "venue": { "en": "Southern Dunes Observatory", "ar": "مرصد الكثبان الجنوبية" },
  "capacity": 8,
  "lat": 25.4, "lon": 37.9,
  "open_days": ["Mon", "Wed", "Thu", "Fri"],
  "tagline": { "en": "Mon · Wed · Thu · Fri", "ar": "الاثنين · الأربعاء · الخميس · الجمعة" },
  "sessions": ["8:00–9:00 PM", "9:30–10:30 PM"],
  "booking": { "en": ["Guest’s Name", "Pax"], "ar": ["اسم الضيف", "عدد الأشخاص"] },
  "booking_note": { "en": "Please book via AKUN.Support@Akun.com", "ar": "يتم الحجز عبر AKUN.Support@Akun.com" },
  "months": []
}
```

- `id`: إنجليزي بدون مسافات.
- `aliases`: الأسماء اللي ممكن الموظف يكتبها في البحث.
- `lat` و`lon`: إحداثيات المكان، تُستخدم لحساب القمر.
- `sessions`: أوقات الجلسات، وعددها حر.
- `open_days`: أيام التشغيل. الأيام اللي برا القائمة تظهر «غير متاح»، واتركها `[]` إذا المنتجع يشتغل يومياً.
- `booking` و`booking_note`: متطلبات الحجز وطريقته، لكل منتجع.

المنتجعات الحالية: **Desert Rock** (يومياً، 4 جلسات)، **Six Senses** (الاثنين والأربعاء والخميس والجمعة، جلستين)، **St. Regis** (كل جمعة).

بعد الحفظ يتولد جدول المنتجع تلقائياً خلال دقائق.

## أدوات إضافية (اختيارية)

```bash
pip install -r tools/requirements.txt
python tools/generate_month.py --month 2027-03                 # توليد شهر
python tools/xlsx_to_json.py "AKUN_Astronomy_Dec-2026.xlsx" --resort desert-rock   # استيراد من Excel
python -m http.server   # تجربة محلية على http://localhost:8000
```
